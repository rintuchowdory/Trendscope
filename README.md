TrendScope is a modern, responsive website for a trend analytics platform that provides real-time market intelligence and actionable insights for data-driven teams.

## 🚀 Features

- **Landing Page** — Hero section with animated dashboard preview, feature grid, live analytics demo, pricing tiers, testimonials, and CTA
- **Interactive Dashboard Demo** — Canvas-based chart with multiple trend datasets (AI, Green Tech, Remote Work, Crypto) and animated transitions
- **About Page** — Company mission, values, team profiles, and key statistics
- **Contact Page** — Contact form, company info, and FAQ accordion
- **Responsive Design** — Fully responsive across desktop, tablet, and mobile
- **Dark Theme** — Modern dark UI with gradient accents (indigo → cyan)
- **Smooth Animations** — Intersection Observer-based scroll animations, counter animations, and canvas chart transitions

## 🛠️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rintuchowdory/Trendscope.git
   ```

2. Navigate to the project:
   ```bash
   cd Trendscope
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js
   npx serve .
   ```

4. Visit `http://localhost:8000`
